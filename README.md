# DevPulse

DevPulse is a full-stack GitHub developer analytics dashboard that transforms GitHub profile and repository data into meaningful developer insights and visualizations.

## Features

- Search developers by GitHub username
- View developer profile statistics
- Analyze repository activity
- Explore programming language distribution
- Discover top repositories
- Visualize GitHub development metrics

## Tech Stack

### Frontend
- React
- JavaScript
- Recharts

### Backend
- FastAPI
- Python
- GitHub REST API
